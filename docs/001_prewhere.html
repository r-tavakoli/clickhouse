⚡ What is PREWHERE?

This is one of the most important ClickHouse optimizations.

Suppose your table has:

order_date
customer_id
country
price
quantity
status

and you run:

SELECT *
FROM orders
WHERE order_date >= today() - 30;

A traditional database roughly does:

Read every column ↓ Apply WHERE ↓ Return rows

ClickHouse is smarter.

It does something like:

Read only order_date ↓ Apply filter ↓ Determine matching rows ↓ Read the remaining columns

This optimization is called PREWHERE.

Why is it faster?

Imagine:

100 million rows

Only

3 million

match the filter.

Without PREWHERE:

Read

customer_id
price
status
country
quantity
...

for 100 million rows

With PREWHERE:

Read only

order_date

↓

Find 3 million matching rows

↓

Now read the other columns

✅ Much less disk I/O.

Disk I/O is usually the expensive part.
